## ObjectReplacer.cs — 一括置換エディタ拡張

SpeedTree で作り直した杉を、シーンに配置済みの木へ一括で差し替えるためのエディタ拡張です。

- **検索 → 一覧で確認 → 確認ダイアログ → 実行** の順でしか置換できないようにして、誤操作を防いでいます
- 既存の Prefab を除外したり、`LODGroup` を持つものだけに絞ったりして、子の LOD0 などの誤検出を防ぎます
- 位置・回転は常に引き継ぎ、Scale・名前・子オブジェクトは選んで引き継げます
- Undo を 1 グループにまとめ、**Ctrl+Z 1 回で全件を元に戻せます**

**結果**

| | before | after |
|---|---|---|
| 1 本あたり | 3,200 tris | 3,003 tris（LOD 付き） |
| 本数 | 540 本 | 453 本 |
| 木の合計 | 約 173 万 tris | **約 136 万 tris（約 21% 減）** |

使い方：メニューの `Tools > Object Replacer` から開きます。

## RingSpectrumBars.cs — オーディオビジュアライザー

オープニングのガレージシーンで、BGM に合わせて車の周りを囲むリング状のエフェクトです。
テクスチャを使わず、FFT の結果から毎フレーム動的メッシュを生成しています。

1. `GetSpectrumData` で BGM を FFT 解析（4096 サンプル）
2. 担当する周波数帯をバーの本数ぶんに **対数で** 割り当て（人の聴こえ方に合わせるため）
3. 音量を dB に変換して 0〜1 の長さにする
4. **伸びるときは速く、戻るときはゆっくり** 動かして余韻を残し、隣同士を平均して機械的な動きを消す
5. 全バーを 1 つの動的メッシュにまとめて更新

帯域・本数・伸びる向き（上 / 外 / 内）・「棒 / 帯」をパラメータで切り替えられるので、高音・中音・低音の 3 つのリングを同じスクリプトで作っています。

## G923_FFBController.cs — フォースフィードバック（共同制作）

**中田樹希との共同制作** です。ファイル冒頭と各セクション見出しの `[担当: ○○]` で、担当を分けて記載しています。

**中里の担当**

- **路面振動**：3 種類の路面エフェクト（BumpyRoad / DirtRoad / Surface）を、ランダムな間隔・強さ・種類で発生させます
  - 発生しやすさは速度の 2 乗、強さは速度に比例して大きくなり、高速ほど振動が短く鋭くなります
- **壁衝突**：接触した側に応じてハンドルを逆方向に取られ、その力が時間とともに弱まります

**中田の担当**：SDK 連携、USB 切断・復帰処理、センタリング・ダンパー、全体のパラメータ調整など

> 実行には Logitech Gaming SDK が必要です（このリポジトリには含めていません）。
